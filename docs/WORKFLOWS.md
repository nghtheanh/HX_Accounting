# SOP nghiệp vụ
- Bán hàng: Zalo -> gia đình/bán hàng tư vấn -> thiết kế -> khách chốt -> mã đơn -> quản lý tiếp nhận -> MTO hoặc cấp hàng MTS -> giao từng phần/QC -> ghi nhận doanh thu đủ điều kiện -> thu/đối soát -> lãi gộp. Trạng thái sản xuất, giao hàng, thanh toán độc lập.
- Mua hàng: nhu cầu BOM/tồn -> đề nghị -> duyệt -> đơn mua -> nhận và QC -> nhập kho -> đối chiếu hóa đơn -> công nợ -> thanh toán. Chênh lệch giá/lượng tạo exception.
- Sản xuất: quản lý xác nhận BOM/lệnh, đội cắt bàn giao đội may, quản lý kiểm QC và tổng hợp sản lượng; ghi nhận xuất vải, vật tư trả lại, hàng lỗi, WIP, thành phẩm. Không yêu cầu công nhân trực tiếp nhập.
- Gia công: phiếu giao vật tư tới khu logic ngoài xưởng, nhận từng phần, xác nhận đạt/lỗi, ghi phí và đối chiếu công nợ; tồn thuộc công ty vẫn được theo dõi.
- Thu chi: kế toán lập, rule phân loại; khoản thường tự duyệt theo hạn mức loại chi, đặc biệt chủ duyệt. Không có rule thì chuyển chủ. Chặn chia nhỏ giao dịch bằng cảnh báo tổng theo đối tác/ngày/nhóm. Duyệt không thực hiện chuyển tiền. Ghi nhận và đối soát độc lập.
- Lương: import máy -> map nhân viên -> quản lý xác nhận công/sản lượng -> kế toán tính -> chủ duyệt -> ghi sổ -> thanh toán -> phân bổ chi phí.
- Cuối tháng: kiểm kê, đối soát quỹ/ngân hàng/nợ, chốt lương/giá thành, khấu hao/phân bổ, kiểm tra sổ phụ, kết chuyển, khóa kỳ, xuất báo cáo cho kế toán thuế.
