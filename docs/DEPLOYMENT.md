# Runbook VPS (đề xuất)
Dev/staging/prod tách DB, secrets, storage. VPS Linux cập nhật bảo mật, SSH key, firewall chỉ 443/80 và SSH giới hạn; reverse proxy TLS; container non-root, resource limits, health checks. CI build/test/migration rehearsal, image tag immutable; backup DB trước migration, kiểm tra tương thích, rollout có phê duyệt. Không chạy destructive migration tự động. Giám sát CPU/RAM/disk, DB connections, latency/error, backup age, outbox lag. Backup daily encrypted offsite + WAL archive nếu đáp ứng RPO; thử restore isolated hàng tháng và đo RTO. Sự cố: ngừng ghi nếu integrity lỗi, lưu log, báo chủ/kế toán, phục hồi và đối soát; không sửa SQL trực tiếp để cân sổ. Chưa có VPS/tên miền/credentials; không cung cấp cấu hình production giả.
