# Mẫu chuyển đổi DEMO

`opening_template.csv` và `transactions_template.csv` chứa toàn bộ hàng ví dụ DEMO. Mã 111 trong file mở kỳ thuộc ví dụ sandbox trong ACCOUNTING_RULES. Hai file minh họa cách biểu diễn dữ liệu, chưa đủ trường để import thực tế. Xem [kế hoạch chuyển đổi](../docs/MIGRATION.md).
